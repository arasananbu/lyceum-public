# What is an Eval? Grading an AI Like a Test Plan. AI means artificial intelligence

## The big idea
An agent is software that can look at a goal, choose a useful tool, take a small step, and check
whether the step helped. Think of it as a careful helper, not a magic brain. It still needs clear
instructions, useful context, safe tools, and a way to notice mistakes. Today, the important idea is
What is an Eval? Grading an AI Like a Test Plan. We learn it in tiny pieces so every learner can connect it to testing, operations, product
work, data work, or daily coding practice.

## An analogy
Imagine teaching a friend to make tea in your kitchen. A normal chatbot can explain tea. An agent can
read the recipe, open the cabinet, pick the cup, boil water, and check whether the tea is ready. If
the cup is missing, it should stop and ask instead of guessing. That is the shape of agentic work:
goal, context, tool, action, check, then the next safe step.

## Try this today
Open one coding assistant you already use and ask it for a two-step plan before it edits anything.
Then ask what context it needs, what tool it would use, and how it would verify success. You are not
only asking for code. You are practicing harness thinking: the wrapper around the model that makes
the work reliable, reviewable, and useful.
